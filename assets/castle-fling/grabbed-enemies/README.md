# Castle Fling Grabbed / Scared Enemy Sprite Pack

This pack contains individual transparent PNGs for the enemy state shown while the player is holding/grabbing an enemy.

## Includes
- 10 scared humanoid enemy sprites
- 2 neutral grabbed siege-unit sprites
- `asset-manifest.json` with exact base-enemy mappings
- contact sheet preview

## Important
The two siege weapons do not have scared faces by design:
- `enemy_bomb_cart_grabbed`
- `enemy_twin_ram_grabbed`

Do not use the older sheet that had giant fingers grabbing the enemies. This pack has the fingers removed.
