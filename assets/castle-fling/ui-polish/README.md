# Castle Fling UI Polish Sprite Pack

Install-ready transparent PNG sprite pack for remaining UI/effect placeholders.

## Included categories
- Settings icons
- How to Play icons
- Castle HUD life bar assets
- Enemy death/ground impact marks
- Castle damage stages
- Dangerous Bargain icons

## Install location
Unzip into:
`assets/castle-fling/ui-polish/`

Use `asset-manifest.json` for exact IDs, file paths, and notes.
Use `PROMPT_FOR_CODEX.md` as the implementation prompt.
