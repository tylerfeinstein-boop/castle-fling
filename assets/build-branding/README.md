# Castle Fling App Icon Pack

Included assets:
- `icons/app_icon_1024.png` — master 1024x1024 app icon
- `icons/app_icon.ico` — Windows ICO for EXE/shortcut packaging

Recommended usage:
- **Windows portable EXE / desktop build**: use `app_icon.ico` for the executable, window icon, shortcuts, and installer branding if applicable.
- **Android wrapper**: use `app_icon_1024.png` as the source app icon/adaptive icon artwork.
- **Web / PWA**: use `app_icon_1024.png` and derive smaller sizes as needed (512, 192, 180, 32).
